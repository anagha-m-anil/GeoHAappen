# GeoHappen 🎯  
A Geo-Location Based Event Finder Web Application  

## 🌍 Overview
GeoHappen is a full-stack web app that allows users to discover, create, and interact with events based on their location.  
Built using **JavaScript (Vanilla)**, **Node.js**, **Express.js**, **Firebase Firestore**, and **Google Maps API**.

## ⚙️ Features
- User authentication (Register/Login)
- Create, view, and delete events
- Interactive map with event markers
- Event filtering (by date & category)
- Recommendation system based on likes

## 🧠 Tech Stack
JavaScript (Vanilla), Node.js, Express.js, Firebase Authentication, Firestore, Google Maps JavaScript API, Geolocation API, HTML, CSS
